# LiquidCounter

Компактный десктопный счётчик для Windows в стиле **liquid glass** — полупрозрачное окно, которое всегда под рукой.

---

## О проекте

LiquidCounter — это минималистичный виджет-счётчик, который висит в углу экрана поверх других окон и позволяет быстро считать повторяющиеся действия: чашки кофе, выполненные задачи — что угодно.

---

## Установка

1. Перейдите в раздел [Releases](../../releases).
2. Скачайте последний `LiquidCounter.exe`.
3. Положите в любое удобное место и запустите.
